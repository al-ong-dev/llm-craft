  KEY CHANGES: BEFORE vs AFTER
═══════════════════════════════════════════════════════════════════════════════

BEFORE (Mock Voting):
  Agent receives phase instruction
    → Auto-vote "proceed" (hardcoded)
    → Submit vote with empty findings
    → Done (30ms)

AFTER (Skill-Driven):
  Agent receives phase instruction
    → Query SKILLS.json for phase+agent skills
    → Execute each skill in order
    → Aggregate findings
    → Generate decision from findings
    → Submit vote with detailed findings
    → Done (40-60 seconds)

TRADE-OFF: Speed vs. Thoroughness
  • Before: Fast but uninformed (mock voting)
  • After: Thorough but slower (real analysis)
  • With caching: Fast AND thorough (70-80% speedup on cache)
