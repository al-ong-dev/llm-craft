## 🎯 What Agents Can Now Do

### Query State
```bash
./scripts/workflow-state-manager.sh status <workflow_id>
./scripts/workflow-state-manager.sh phase <workflow_id> <phase>
./scripts/workflow-state-manager.sh consensus <workflow_id> <phase>
```

### Run Skills  
```bash
./scripts/skill-executor.sh --skill <skill_name> --context $CONTEXT_FILE
./scripts/skill-executor.sh --list-skills --phase <num>
./scripts/skill-executor.sh --list-skills --agent <agent_id>
```

### Submit Votes
```json
{
  "agent_id": "researcher",
  "phase": 2,
  "vote": "proceed|escalate|blocked|needs_info",
  "findings": "...",
  "confidence": 0.92
}
```
